# TOP Server Manager Ultimate 2.0 — คู่มือภาษาไทย

โปรแกรม Windows (Rust + Tauri 2) สำหรับรันและเปิดโฮสต์เว็บไซต์ / เกมเซิร์ฟเวอร์หลายตัวพร้อมกันจากหน้าต่างเดียว
พร้อมระบบฐานข้อมูลอัตโนมัติ (Universal Auto Database Engine) และระบบเปิดโฮสต์หลายรูปแบบ

---

## 1. ติดตั้ง

1. ดับเบิลคลิก `TOP-Server-Manager-Setup.exe` → เลือกภาษา → เลือกโฟลเดอร์ → ติดตั้ง
   - ติดตั้งแบบผู้ใช้ปัจจุบัน (ไม่ต้องใช้สิทธิ์ Administrator)
   - สร้าง Shortcut บน Desktop และ Start Menu และมีตัวถอนการติดตั้ง
   - ถ้าเครื่องยังไม่มี WebView2 ตัวติดตั้งจะดาวน์โหลดจาก Microsoft ให้อัตโนมัติ
2. **คำเตือน SmartScreen:** ตัวติดตั้งรุ่นนี้ *ยังไม่ได้ลงลายเซ็นดิจิทัล (Code Signing)*
   Windows อาจแสดง “Windows protected your PC” ให้กด **More info → Run anyway**
   หากต้องการแจกจ่ายสาธารณะ ควรซื้อใบรับรอง Code Signing (OV/EV) แล้วเซ็นไฟล์ด้วย `signtool`
   (Tauri รองรับผ่าน `bundle.windows.certificateThumbprint` / `signCommand`) — ใบรับรอง EV จะลดคำเตือนได้เร็วที่สุด
3. ติดตั้งทับเวอร์ชันเดิมได้ (Upgrade / Repair) — ข้อมูลเดิมไม่หาย

### ถอนการติดตั้ง
- Settings → Apps → TOP Server Manager → Uninstall
- ช่อง “Delete the application data” ไม่ถูกเลือกไว้ (ค่าเริ่มต้น) → การตั้งค่าและรันไทม์ยังอยู่
- **ฐานข้อมูลและไฟล์สำรอง** อยู่ใน `%LOCALAPPDATA%\TOP Server Manager Data` ซึ่ง *ตัวถอนการติดตั้งไม่ลบเลย*
- **โฟลเดอร์โปรเจกต์/เกมของคุณ** ไม่ถูกแตะต้องในทุกกรณี

## 2. ตำแหน่งข้อมูล (แยกจากกันชัดเจน)

| ประเภท | ตำแหน่ง |
|---|---|
| ไฟล์โปรแกรม | `%LOCALAPPDATA%\TOP Server Manager` |
| การตั้งค่า / รายการเซิร์ฟเวอร์ / Secret (DPAPI) | `%APPDATA%\com.topserver.manager` |
| Runtime (PHP, Caddy, Node, Java, MariaDB, agents) | `%LOCALAPPDATA%\com.topserver.manager\runtimes` |
| Log / PID / ไฟล์ config ที่สร้างอัตโนมัติ | `%LOCALAPPDATA%\com.topserver.manager\state` |
| ฐานข้อมูล SQLite / MariaDB ที่โปรแกรมจัดการ | `%LOCALAPPDATA%\TOP Server Manager Data\databases` |
| ไฟล์สำรอง | `%LOCALAPPDATA%\TOP Server Manager Data\backups` |
| โปรเจกต์ | โฟลเดอร์ที่คุณเลือก (เช่น `D:\Games\UNO`) |

## 3. เริ่มใช้งานเร็ว — UNO Ultimate

1. เมนู **Runtime Manager** → ติดตั้ง **PHP** และ **Caddy** (ดาวน์โหลดจากแหล่งทางการ ตรวจ SHA-256 ก่อนติดตั้ง)
2. เมนู **Add Server** → เลือก **UNO Ultimate** → โฟลเดอร์ `D:\Games\UNO` (ถ้าไม่มีไดรฟ์ D: ให้เลือกโฟลเดอร์อื่น)
   - ถ้าโฟลเดอร์มีเกมอยู่แล้ว → โปรแกรม **ไม่สร้าง/ไม่เขียนทับไฟล์ใด ๆ**
   - ถ้าโฟลเดอร์ว่าง → สร้าง *หน้าเริ่มต้น PHP* + migration ของจริง (แจ้งชัดว่า **ยังไม่ใช่เกมเต็ม**)
3. กด **Start** → โปรแกรมทำตามลำดับ:
   ตรวจ config → ตรวจพอร์ต 8001 → สร้างไฟล์ SQLite (นอก public web root) → รัน migration → เปิด php-cgi + Caddy → ตรวจ HTTP health
4. กด **Open Website** → `http://127.0.0.1:8001`

## 4. เมนูหลัก

- **Dashboard** — จำนวนเซิร์ฟเวอร์, ที่กำลังรัน, Public Online (ยืนยันจากปลายทางจริง), CPU/RAM/Network, ผู้เล่น (เฉพาะเกมที่รายงานได้จริง), Log ล่าสุด
- **My Servers** — การ์ดเซิร์ฟเวอร์ Start / Stop / Restart / Force Stop / Open Folder / Open Website / Copy Address / Console / Edit / Duplicate / Export / Import
- **Add Server** — เทมเพลต UNO, Minecraft Fabric, Minecraft Bedrock, Node.js Game, Custom Executable, Static Website
- **Hosting / Network** — Wizard 10 ขั้นตอน + วิเคราะห์เครือข่าย
- **Database Manager** — Database Auto Setup
- **Runtime Manager** — ติดตั้ง / อัปเดต / เลือกเวอร์ชัน / ตรวจสอบ / ซ่อม
- **Resource Monitor** — CPU/RAM ต่อเซิร์ฟเวอร์ (รวมทั้ง process tree ใน Job Object), ประวัติแบบจำกัดขนาด
- **Server Logs** — Log สด ค้นหา กรอง คัดลอก ส่งออก ล้างหน้าจอ เลื่อนอัตโนมัติ ส่งคำสั่งเข้า stdin
- **Backups** — สำรองฐานข้อมูล / ไฟล์โปรเจกต์ ตามเวลา พร้อมเก็บจำนวนล่าสุด
- **Settings** — ภาษาไทย/อังกฤษ, Dark/Light, Performance Mode, พฤติกรรมปิดหน้าต่าง, เริ่มพร้อม Windows

## 5. การจัดการเซิร์ฟเวอร์

- แต่ละเซิร์ฟเวอร์รันใน **Windows Job Object** ของตัวเอง → หยุดได้ทั้ง process tree และจำกัด RAM/CPU ได้
- **ไม่ฆ่าโปรแกรมตามชื่อ** — ยืนยันความเป็นเจ้าของด้วย PID + เวลาเริ่ม process + path ของไฟล์
- Graceful stop: ส่งคำสั่ง (เช่น `stop` ของ Minecraft) → รอ → ค่อยปิด
- **Auto Restart** พร้อม backoff (1s, 2s, 4s … สูงสุด 60s) และ **Crash Loop Protection** (5 ครั้งใน 5 นาที → หยุดและแจ้ง)
- ตรวจจับ: พอร์ตชน (บอกชื่อ/PID โปรแกรมที่ใช้อยู่), process crash, permission denied, ไม่พบไฟล์, config ผิด, runtime ไม่ได้ติดตั้ง, เชื่อมต่อฐานข้อมูลไม่ได้
- เปิดโปรแกรมใหม่ → **Re-attach** เซิร์ฟเวอร์ที่ยังรันอยู่ได้อย่างปลอดภัย (ยืนยัน PID + เวลาเริ่ม)

### เมื่อปิดหน้าต่าง (Settings)
| ตัวเลือก | ผล |
|---|---|
| Minimize to tray (ค่าเริ่มต้น) | หน้าต่างซ่อนไป tray เซิร์ฟเวอร์รันต่อและยังมีการดูแล (auto restart, health check, tunnel) |
| Exit, keep servers | ปิดโปรแกรม เซิร์ฟเวอร์รันต่อ (เปิดใหม่จะ re-attach) — *ระหว่างที่ปิด ไม่มี auto restart และ tunnel จะปิด* |
| Exit, stop servers | หยุดทุกเซิร์ฟเวอร์อย่างนุ่มนวลแล้วปิด |

> โปรแกรมนี้ **ไม่ได้อ้างว่าเป็น Windows Service** — การดูแลเบื้องหลังทำใน tray process จริง

## 6. Universal Auto Database Engine

### การตรวจจับโปรเจกต์
`topserver.json` → Laravel (`artisan` + `laravel/framework`) → `.env` / `.env.example` → `config.php` → `database/migrations/*.sql` → `schema.sql`

### ไฟล์ `topserver.json` (แนะนำ)
```json
{
  "name": "UNO Ultimate",
  "web_root": "public",
  "health": { "path": "/health.php" },
  "database": {
    "driver": "sqlite",
    "name": "uno",
    "migrations": "database/migrations",
    "schema": "database/schema.sql",
    "seeds": ["database/seed.sql"],
    "config_adapter": "env",
    "env": { "MY_DB_FILE": "{database_path}" }
  }
}
```
- ไฟล์ migration: `0001_ชื่อ.sql` เรียงตามตัวเลข, ใช้ไฟล์เฉพาะ driver ได้ เช่น `0001_init.sqlite.sql` / `0001_init.mysql.sql`
- ตัวแปรที่ส่งให้แอป: `DB_CONNECTION`, `DB_DATABASE` (path SQLite) หรือ `DB_HOST/DB_PORT/DB_DATABASE/DB_USERNAME/DB_PASSWORD`

### กฎความปลอดภัย
- ไม่ Drop ฐานข้อมูล / ไม่ลบตารางเดิม / ไม่เดาโครงสร้างตารางเอง
- Migration ที่ประกาศใน `topserver.json` ถือว่าเชื่อถือได้ → รันอัตโนมัติเมื่อกด Start (โหมด Local)
- Migration ที่ “พบตามธรรมเนียม” (`database/migrations`, `schema.sql`), Laravel `artisan migrate`, คำสั่งอันตราย (DROP/TRUNCATE/DELETE ไม่มี WHERE ฯลฯ) หรือเซิร์ฟเวอร์ที่เปิดสาธารณะ → **ต้องดู Preview และกดอนุมัติ** (อนุมัติผูกกับ hash ของไฟล์ชุดนั้นเท่านั้น)
- สำรองข้อมูลอัตโนมัติก่อน migrate ฐานข้อมูลที่มีข้อมูลอยู่แล้ว
- SQLite: แต่ละ migration อยู่ใน transaction → ล้มเหลวจะ rollback; เปิด foreign keys, busy timeout 5s, WAL
- MySQL/MariaDB: DDL อาจ commit เอง จึงสำรองก่อนเสมอ
- ประวัติใน `_topserver_migrations` — ไม่รันซ้ำ, ไฟล์ที่แก้หลังรันจะแจ้งเตือนแต่ไม่รันซ้ำ
- ล็อกป้องกันการ Setup ซ้อนกัน (ทั้งในโปรแกรมและข้าม process)
- ผู้เข้าชมเว็บไม่สามารถสั่งสร้าง/แก้ฐานข้อมูล — ทุกอย่างทำจาก Server Manager ก่อนเปิดบริการ
- ไฟล์ SQLite เก็บนอก public web root เสมอ และ Caddy บล็อก `*.sqlite`, `.env`, `topserver.json`, `/database/*`

### MariaDB/MySQL
- **Managed**: ติดตั้ง MariaDB จาก Runtime Manager → โปรแกรมสร้าง data dir, รันที่ `127.0.0.1:3307`, ตั้งรหัส root แบบสุ่ม (เก็บด้วย DPAPI) และสร้าง **ผู้ใช้แยกต่อโปรเจกต์** (`tsm_<db>`) ที่มีสิทธิ์เฉพาะฐานข้อมูลของตัวเอง
- **External**: ใส่ host/port/user/password (เก็บเข้ารหัส) — ถ้าไม่มีสิทธิ์ CREATE โปรแกรมจะบอกวิธีแก้ (GRANT)
- ไม่เปิดพอร์ตฐานข้อมูลสู่อินเทอร์เน็ต (3306/3307/5432/6379 … ถูกปฏิเสธในทุก provider)

## 7. การเปิดโฮสต์ (Hosting)

ค่าเริ่มต้นคือ **Localhost** เสมอ — เปิดสาธารณะต้องผ่าน Wizard และกดยืนยันความเสี่ยง
สถานะ **Public Online** แสดงเมื่อปลายทางสาธารณะตอบกลับจริงเท่านั้น (HTTP ผ่าน edge, TCP connect, Minecraft ping) — แค่ agent กำลังรันไม่นับ

| วิธี | เหมาะกับ | ข้อจำกัดสำคัญ |
|---|---|---|
| Localhost | พัฒนา | เฉพาะเครื่องนี้ |
| LAN | เพื่อนวงแลนเดียวกัน | ต้องตั้ง Listen on = LAN และกฎ Firewall (ขออนุญาต + UAC, เปิดเฉพาะ Private profile) |
| Direct IP | Minecraft/เกม เมื่อมี Public IP | ใช้ไม่ได้หลัง CGNAT/Double NAT; ต้อง Port Forward (หรือ UPnP/NAT-PMP เมื่อยืนยัน); ยืนยันจากภายนอกได้เท่านั้น |
| Cloudflare Tunnel | เว็บ / เกมบนเบราว์เซอร์ / WebSocket | ต้องมีโดเมนบน Cloudflare (หรือ Quick tunnel สำหรับทดสอบ); **Raw TCP/UDP เช่น Minecraft ไม่เปิดสาธารณะได้โดยไม่ติดตั้ง client** (ต้อง `cloudflared access` หรือ Spectrum แบบเสียเงิน) |
| ngrok | เว็บ, TCP (บัญชีต้องผูกบัตร) | ไม่มี UDP; URL อาจเปลี่ยนเมื่อเริ่มใหม่ |
| playit.gg | Minecraft Java/Bedrock, เกม UDP | ต้อง claim agent ครั้งแรก, สร้าง tunnel ในแดชบอร์ด; TCP ทั่วไปอาจต้อง Premium |
| FRP + VPS | ทุกโปรโตคอล | ต้องมี VPS ของคุณเอง (มีสคริปต์ติดตั้ง frps ให้ *คุณรันเอง*) |
| Tailscale | เซิร์ฟเวอร์ส่วนตัว | ผู้เล่นต้องติดตั้ง Tailscale/ได้รับแชร์; Funnel (สาธารณะ) รองรับเฉพาะ HTTPS พอร์ต 443/8443/10000 |

### ตัวอย่าง Cloudflare (UNO → uno.example.com)
1. Cloudflare Zero Trust → Networks → Tunnels → Create tunnel (cloudflared) → คัดลอก token
2. เพิ่ม Public Hostname `uno.example.com` → Service `http://127.0.0.1:8001`
3. ใน Wizard: Provider = Cloudflare → วาง token (เก็บด้วย DPAPI) → Hostname = `uno.example.com` → ยืนยัน → Start hosting
4. โปรแกรมตรวจ `/ready` ของ cloudflared แล้วเรียก `https://uno.example.com` จริง → แสดง Public Online เมื่อได้รับคำตอบ

### วิเคราะห์เครือข่าย
แสดง LAN IP, Gateway, Router WAN IP (UPnP/NAT-PMP), Public IP (ถามก่อนติดต่อ api.ipify.org), IPv6 และจำแนก **Public on host / Single NAT / Double NAT / CGNAT / Unknown**
ไม่อ้างว่าพอร์ตเปิดจากภายนอกได้ด้วยการทดสอบจากเครื่องตัวเอง (การทดสอบ hairpin จะระบุชัดว่าไม่ใช่หลักฐาน)

### เปิดเว็บใน 1 คลิก (หน้า โฮสต์ / เครือข่าย)
เลือก **ลิงก์ชั่วคราว** / **โดเมนของฉัน** / **เฉพาะในบ้าน** → ติ๊กยืนยัน → **เปิดเลย** โปรแกรมเปิดเซิร์ฟเวอร์ ตั้งค่า ไฟร์วอลล์ เชื่อมต่อ และตรวจสอบให้เอง

### Cloudflare Tunnel กลาง (หลายเว็บ)
- วาง token ครั้งเดียว (วางคำสั่ง `cloudflared ... eyJ...` ทั้งบรรทัดได้) ใช้ร่วมทุกเว็บ ใช้ connector ตัวเดียว
- ตาราง “ชื่อเว็บ → พอร์ต” อ่านจาก Cloudflare จริง ถ้าพอร์ตไม่ตรงจะขึ้น ⚠ พร้อมปุ่ม **แก้ให้ตรง** (เปลี่ยนพอร์ตเว็บแล้วรีสตาร์ทให้)
- ถ้าคุณติดตั้ง `cloudflared service install` เองไว้ (Windows Service ชื่อ Cloudflared) ตัวนั้นก็ยังทำงานแยกอยู่ — ถอนได้ด้วย `cloudflared service uninstall` ถ้าต้องการให้โปรแกรมนี้จัดการอย่างเดียว

### เปิดอัตโนมัติเมื่อเปิดเครื่อง
สวิตช์ **เปิดอัตโนมัติเมื่อเปิดเครื่อง** บนการ์ดเซิร์ฟเวอร์แต่ละตัว — เปิดแล้วโปรแกรมจะเริ่มพร้อม Windows (ย่อไว้ที่ถาด) เปิดเว็บนั้นเอง และถ้าเปิดลิงก์สาธารณะไว้ก่อนปิดเครื่อง ลิงก์จะกลับมาเอง · ปิดสวิตช์ตัวสุดท้ายแล้วโปรแกรมจะไม่เริ่มพร้อม Windows

### แก้ไขข้อมูลในตาราง (หน้า ฐานข้อมูล → ข้อมูลในตาราง)
- เลือกตาราง → ดู/ค้นหา/เรียง · **ดับเบิลคลิกช่องเพื่อแก้** (Enter บันทึก) · เพิ่มแถว · เลือกแล้วลบ
- คอลัมน์รหัสผ่าน/token ถูกซ่อนเป็น •••••• (กด “แสดงรหัสผ่าน” เพื่อดู)
- ระบุแถวด้วย Primary Key เสมอ (ตารางที่ไม่มี Primary Key แก้ได้ทางคำสั่ง SQL เท่านั้น)
- **พิมพ์คำสั่ง SQL**: SELECT รันทันที · คำสั่งแก้ข้อมูลถามยืนยัน · DROP/TRUNCATE/DELETE ไม่มี WHERE ต้องยืนยันซ้ำ · สำรองฐานข้อมูลก่อนแก้ทุกครั้ง (อย่างน้อยทุก 10 นาที และทุกครั้งที่ลบ)

### เพิ่มเว็บง่ายที่สุด: “เพิ่มจากโฟลเดอร์”
เมนู **เพิ่มเซิร์ฟเวอร์** (หรือหน้าแรกตอนยังไม่มีเว็บ) → **เลือกโฟลเดอร์** → โปรแกรมบอกเองว่าเป็น PHP / Node / Minecraft / HTML และใช้ฐานข้อมูลอะไร → **เพิ่มและเริ่มเลย**
- ถ้าขาดโปรแกรม (PHP, Caddy, MariaDB, Java…) จะขึ้นหน้าต่าง **“ติดตั้งให้เลย แล้วเริ่มเซิร์ฟเวอร์”** กดปุ่มเดียว
- ถ้าพอร์ตชนกับโปรแกรมอื่น จะมีปุ่ม **“ใช้พอร์ตว่างแทน แล้วเริ่มเลย”**
- โหมด **โดเมนของฉัน**: วาง token + ใส่ชื่อเว็บ → **เปิดเลย** โปรแกรมเชื่อม tunnel ตรวจชื่อเว็บใน Cloudflare และ **ปรับพอร์ตให้ตรงเอง** ในขั้นเดียว

### การป้องกันเว็บ (เปิดอยู่แล้วโดยอัตโนมัติ)
- ไฟล์สคริปต์ในโฟลเดอร์อัปโหลด (`uploads`, `files`, `storage` …) **รันไม่ได้** — กันคนอัปโหลด .php มายึดเครื่อง (ปรับรายชื่อโฟลเดอร์ได้ที่ แก้ไขการตั้งค่า → ขั้นสูง → ความปลอดภัยของเว็บ)
- ส่ง security headers กันเว็บถูกฝังในเว็บอื่น · ซ่อนไฟล์ลับและไฟล์ที่ขึ้นต้นด้วยจุด
- การตั้งค่าเหล่านี้มีผลหลังกด **รีสตาร์ท** เว็บ 1 ครั้ง · รายละเอียดใน `SECURITY_REVIEW.md`

### ย้ายมาจาก XAMPP / Laragon
1. หน้า **เพิ่มเซิร์ฟเวอร์** → การ์ด **“ย้ายเว็บมาจาก XAMPP / Laragon”** → กด **ค้นหา XAMPP / Laragon ในเครื่อง** (หรือ “เลือกโฟลเดอร์ htdocs เอง”)
2. ติ๊กเว็บที่ต้องการ → **เพิ่ม N เว็บที่เลือก** — ไฟล์เว็บอยู่ที่เดิม ไม่ถูกย้ายหรือแก้ไข
3. ถ้าเว็บใช้ MySQL: เปิด **XAMPP Control Panel → Start ที่ MySQL** แล้วกด **ย้ายข้อมูลจาก MySQL ของ XAMPP** — ข้อมูลถูกคัดลอกมาที่ MariaDB ของโปรแกรม (ฐานข้อมูลเดิมไม่ถูกแตะ, ถ้าตั้งรหัส root ไว้ โปรแกรมจะถามรหัสครั้งเดียวและไม่จำไว้)
4. ปิด Apache/MySQL ของ XAMPP ได้เลย แล้วกด **เริ่ม** ที่เว็บในโปรแกรมนี้

ปุ่มเดียวกันนี้อยู่ที่หน้า **ฐานข้อมูล → ภาพรวม** ด้วย (สำหรับเว็บที่เพิ่มไว้ก่อนแล้ว)

### ไฟล์ .htaccess
เว็บที่เขียนมาสำหรับ Apache/XAMPP ใช้ได้เลย: โปรแกรมแปลงกฎใน `.htaccess` ให้อัตโนมัติ (RewriteRule/RewriteCond แบบที่ใช้กันทั่วไป, Redirect, ห้ามเข้าโฟลเดอร์/ไฟล์, Header, php_value, DirectoryIndex, ErrorDocument)
ดูผลได้ที่ **แก้ไขการตั้งค่า → กฎ .htaccess** — บรรทัดที่แปลงไม่ได้จะแสดงไว้ชัดเจน (เช่น AuthType, จำกัด IP) โปรแกรมไม่เดาเอง และไม่แก้ไฟล์ .htaccess

### phpMyAdmin (คลิกเดียว)
กดปุ่ม **phpMyAdmin** ที่หน้าเซิร์ฟเวอร์หรือหน้าฐานข้อมูล → ครั้งแรกโปรแกรมติดตั้งให้ (จากเว็บทางการ + ตรวจไฟล์) แล้วเปิดในเบราว์เซอร์ **เข้าสู่ระบบให้อัตโนมัติ** ไม่ต้องพิมพ์รหัส
- เปิดได้เฉพาะในเครื่องนี้ (127.0.0.1) และไม่สามารถเปิดออกอินเทอร์เน็ตได้
- ลิงก์เข้าสู่ระบบใช้ได้ครั้งเดียว ภายใน 2 นาที — ถ้าหมดอายุ กดปุ่มในโปรแกรมใหม่

### PostgreSQL
หน้าเซิร์ฟเวอร์ → **แก้ไขการตั้งค่า → ฐานข้อมูล → PostgreSQL** → ตั้งชื่อฐานข้อมูล → บันทึก → กด **เริ่ม** (ครั้งแรกโปรแกรมถามติดตั้ง PostgreSQL ให้ ขนาดประมาณ 48 MB ตรวจ SHA-256)
- โปรแกรมเปิด PostgreSQL ให้เองที่ **127.0.0.1 พอร์ต 5433** (ไม่ชนกับ PostgreSQL ที่อาจติดตั้งไว้แล้วในเครื่องซึ่งใช้ 5432) เข้าได้จากเครื่องนี้เท่านั้น
- แต่ละเว็บได้ฐานข้อมูลและผู้ใช้ของตัวเอง (รหัสผ่านสุ่ม เก็บแบบเข้ารหัส) — เว็บหนึ่งเปิดฐานข้อมูลของอีกเว็บไม่ได้ และไม่ใช่ผู้ดูแลระบบ
- ค่าที่ส่งให้เว็บอัตโนมัติ: `DB_CONNECTION=pgsql`, `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`, `PGHOST`/`PGUSER`/…, `DATABASE_URL` — ใช้ได้กับ Laravel, PHP (PDO `pgsql:`), Node.js, Python (Django) โดยไม่ต้องแก้ไฟล์
- PHP เปิดส่วนเสริม `pdo_pgsql` และ `pgsql` ให้เองเฉพาะเว็บที่ใช้ PostgreSQL
- หน้า **ฐานข้อมูล** ใช้ได้เหมือน MariaDB: ดู/แก้ข้อมูลในตาราง, รันคำสั่ง SQL (คำสั่งอ่านอย่างเดียวรันในโหมดอ่านอย่างเดียวจริง ๆ), สำรอง, กู้คืน, นำเข้า/ส่งออก SQL
- การนำเข้า / กู้คืนทำในธุรกรรมเดียว — ถ้าไฟล์ผิดตรงไหน **ไม่มีอะไรถูกเปลี่ยน**
- ตัว PostgreSQL มาจาก theseus-rs/postgresql-binaries บน GitHub (คอมไพล์จากซอร์สทางการ) เพราะแพ็กเกจทางการของ EDB ใหญ่ 390 MB และไม่มี checksum ให้ตรวจ

### Redis (แคช / คิวงาน / session)
หน้า **ฐานข้อมูล** → การ์ด **Redis** → **ติดตั้งและเปิด Redis** (ครั้งแรกดาวน์โหลดและตรวจ SHA-256 ให้) → ครั้งต่อไปกด **เปิด Redis** / **ปิด**
- เปิดเฉพาะในเครื่องนี้ (127.0.0.1 พอร์ต 6379 หรือพอร์ตว่างถัดไป) และไม่สามารถเปิดออกอินเทอร์เน็ตได้
- เปิดค้างไว้ → โปรแกรมจะเปิดให้เองทุกครั้งที่เปิดโปรแกรม · กด **ปิด** → บันทึกข้อมูลลงดิสก์ก่อนปิด
- ใช้ RAM ได้สูงสุด 512 MB (ถ้าเต็ม Redis จะตอบ error แทนการลบข้อมูลทิ้งเอง)
- กด **วิธีให้เว็บใช้ Redis** เพื่อคัดลอกค่าที่ต้องใส่:
  - **Laravel:** รัน `composer require predis/predis` 1 ครั้ง แล้วตั้ง `REDIS_CLIENT=predis`, `REDIS_HOST=127.0.0.1`, `REDIS_PORT=6379` ใน `.env`
  - **WordPress:** ติดตั้งปลั๊กอิน **Redis Object Cache** แล้วเพิ่ม `define('WP_REDIS_CLIENT', 'predis');` ใน `wp-config.php`
- ตัว Redis สำหรับ Windows มาจากโปรเจกต์ redis-windows บน GitHub (คอมไพล์จากซอร์สของ Redis โดยตรง) เพราะ Redis ไม่มีรุ่น Windows อย่างเป็นทางการ

### Java สำหรับ Minecraft (ใช้รุ่นล่าสุดเสมอ)
- ติดตั้ง Java โดยไม่ระบุรุ่น → ได้ **Java รุ่นล่าสุด** จาก Eclipse Temurin (ตรวจ SHA-256)
- เซิร์ฟเวอร์ใช้ Java รุ่นใหม่ที่สุดที่ติดตั้งไว้เสมอ
- โปรแกรมอ่านจากไฟล์ `server.jar` ว่าต้องใช้ Java รุ่นไหน (Minecraft รุ่นใหม่ต้องใช้ Java 25 ขึ้นไป) — ถ้า Java ในเครื่องเก่าเกินไป ตอนกด **เริ่ม** จะขึ้นหน้าต่าง “ติดตั้งให้เลย แล้วเริ่มเซิร์ฟเวอร์” ให้ทันที
- ครั้งแรกที่เปิด Minecraft ต้องอ่านและยอมรับ EULA เอง (เปลี่ยน `eula=false` เป็น `eula=true` ในไฟล์ `eula.txt`) — โปรแกรมไม่ยอมรับแทน
- ถ้าตั้งเซิร์ฟเวอร์ไว้ว่า **เฉพาะเครื่องนี้** แต่ Minecraft ยังเปิดรับทุกเครือข่าย (`server-ip` ว่างใน `server.properties`) หน้าเซิร์ฟเวอร์จะขึ้นเตือนสีเหลือง กด **จำกัดให้เปิดเฉพาะเครื่องนี้** → ยืนยัน → รีสตาร์ท (สำรองไฟล์เดิมไว้ให้) ถ้าเปิดผ่าน playit.gg หรือ Cloudflare ยังใช้ได้ตามปกติ

### เลือกรุ่น PHP ให้แต่ละเว็บ
**แก้ไขการตั้งค่า → ตั้งค่าหลัก → รุ่น PHP** เลือกได้ตั้งแต่ 7.4 ถึงรุ่นล่าสุด (ตามที่ php.net มีให้) แต่ละเว็บใช้คนละรุ่นได้พร้อมกัน
- ถ้ารุ่นที่เลือกยังไม่มีในเครื่อง ตอนกด **เริ่ม** โปรแกรมจะติดตั้งให้ (ดาวน์โหลดจาก php.net + ตรวจ SHA-256)
- รุ่นที่ขึ้นว่า “หมดอายุ” (ต่ำกว่า 8.2) ใช้ได้ แต่ไม่ได้รับแพตช์ความปลอดภัยแล้ว — ไม่ควรเปิดออนไลน์
- เลือก “ล่าสุดที่ติดตั้งไว้” = ใช้รุ่นใหม่ที่สุดเสมอ

### Composer
เว็บที่มีไฟล์ `composer.json` จะมีปุ่ม **ติดตั้งแพ็กเกจ (composer install)** ในหน้าเซิร์ฟเวอร์ — ครั้งแรกโปรแกรมติดตั้ง Composer ให้ (จาก getcomposer.org + ตรวจ SHA-256) ความคืบหน้าแสดงในคอนโซล ใช้ PHP รุ่นเดียวกับเว็บ · ในเทอร์มินัลพิมพ์ `composer` ได้เลย

### แจ้งเตือนเมื่อล่ม (Discord / Telegram)
**ตั้งค่า → แจ้งเตือนเมื่อเว็บ / เซิร์ฟเวอร์ล่ม**
- **Discord:** ห้องที่ต้องการ → ตั้งค่าห้อง → Integrations → Webhooks → New Webhook → Copy Webhook URL → วางในโปรแกรม
- **Telegram:** คุยกับ @BotFather → `/newbot` → คัดลอก token มาวาง → ส่งข้อความอะไรก็ได้หาบอทของคุณ 1 ครั้ง → กด **ค้นหาให้** (Chat ID จะถูกใส่ให้)
- ติ๊ก **เปิดการแจ้งเตือน** → กด **บันทึกและส่งข้อความทดสอบ**
- แจ้งเมื่อเซิร์ฟเวอร์ล่ม/ลิงก์ออนไลน์เข้าไม่ได้นานเกินที่ตั้งไว้ (ค่าเริ่มต้น 60 วินาที — รีสตาร์ทเองเร็ว ๆ จะไม่รบกวน) และแจ้งอีกครั้งเมื่อกลับมา · การกดหยุดเองไม่แจ้งเตือน
- โปรแกรมต้องเปิดอยู่ (ย่อไว้ที่ถาดได้) จึงจะเฝ้าดูได้ · ถ้าคอมดับทั้งเครื่อง จะไม่มีอะไรส่งข้อความได้

### ติดตั้ง WordPress / Laravel ในคลิกเดียว
หน้า **เพิ่มเซิร์ฟเวอร์ → ติดตั้งแอปใหม่ในคลิกเดียว** → เลือก WordPress หรือ Laravel → ตั้งชื่อ + โฟลเดอร์ใหม่ (ต้องว่าง) → **ติดตั้ง แล้วเริ่มเลย**
- **WordPress:** ดาวน์โหลดรุ่นล่าสุดจาก wordpress.org (ตรวจ checksum SHA-1 ที่ wordpress.org ประกาศ) สร้างฐานข้อมูล MariaDB ให้ และ `wp-config.php` อ่านค่าฐานข้อมูลจากโปรแกรม (ไม่มีรหัสผ่านในไฟล์) → เปิดเว็บแล้ว WordPress จะให้เลือกภาษา (มีภาษาไทย) ตั้งชื่อเว็บและบัญชีผู้ดูแล
- **Laravel:** สร้างด้วย `composer create-project` (1–3 นาที) ใช้ฐานข้อมูล SQLite ของ Laravel เอง
- ถ้าขาด PHP / Caddy / MariaDB / Composer โปรแกรมจะถามติดตั้งให้ก่อน

### ชื่อเว็บ .test + HTTPS
หน้าเซิร์ฟเวอร์ → การ์ด **ชื่อเว็บในเครื่อง (.test + HTTPS)** → พิมพ์ชื่อ (เช่น `myshop.test`) → **ตั้งชื่อนี้**
1. Windows ถามสิทธิ์ผู้ดูแล → กด **Yes** (เพื่อเพิ่มชื่อลงไฟล์ hosts — โปรแกรมแก้เฉพาะบล็อกของตัวเอง และเก็บสำเนาเดิมไว้)
2. ครั้งแรกกด **ติดตั้งใบรับรอง** → Windows ถามยืนยัน → กด **Yes** → ปิดแล้วเปิดเบราว์เซอร์ใหม่ 1 ครั้ง
3. เปิด `https://myshop.test` ได้เลย (มีรูปกุญแจ)
- ต้องใช้พอร์ต 80 และ 443 — ถ้า Apache ของ XAMPP / IIS เปิดอยู่ ให้ปิดก่อน
- ใช้ได้เฉพาะเครื่องนี้ · คนอื่นเข้าผ่านลิงก์ออนไลน์ในหน้าโฮสต์
- เว็บ PHP จะรู้ว่าเป็น HTTPS อัตโนมัติ (ลิงก์ในหน้าเว็บเป็น https)

### อีเมลทดสอบ (Mail catcher)
อีเมลที่เว็บส่ง (PHP `mail()`) **ไม่ถูกส่งออกไปจริง** แต่มาอยู่ที่เมนู **อีเมลทดสอบ** — ใช้ทดสอบระบบสมัครสมาชิก / ลืมรหัสผ่าน / แจ้งเตือนคำสั่งซื้อ
- PHPMailer / Laravel: ตั้ง SMTP host `127.0.0.1` พอร์ต `1025` ไม่ต้องมีรหัสผ่าน
- แสดง HTML แบบปลอดภัย (ไม่รันสคริปต์ ไม่โหลดรูปจากภายนอก) · เก็บล่าสุด 500 ฉบับ
- เว็บที่ส่งอีเมลจริงผ่าน SMTP ของ Gmail ฯลฯ (ตั้งค่าในเว็บเอง) จะไม่ถูกดัก

### เทอร์มินัล
ปุ่ม **เทอร์มินัล** ที่หน้าเซิร์ฟเวอร์ เปิดหน้าต่างคำสั่งในโฟลเดอร์เว็บ พร้อมใช้ `php`, `node`, `mariadb`, `java` ของโปรแกรมทันที (ไม่ต้องตั้ง PATH เอง) และมีค่า `DB_*` เดียวกับที่เว็บได้รับ — เหมาะกับ `php artisan`, `npm install` ฯลฯ

## 8. ความปลอดภัย
- Token / รหัสผ่าน เข้ารหัสด้วย **Windows DPAPI** และไม่ถูกส่งกลับไป UI
- Token ส่งให้ agent ผ่าน environment variable (ไม่อยู่ใน command line) และถูก **Redact** ออกจาก log ทุกบรรทัด
- Frontend เรียกได้เฉพาะคำสั่งที่กำหนด (Typed IPC) — ไม่มี shell/fs ทั่วไป; Rust ตรวจทุก argument
- ไม่รัน .bat/.ps1 ของผู้ใช้; ไฟล์รันได้ต้องเป็น path เต็ม (.exe/.jar/.js/.php) และเรียกตรง ไม่ผ่าน shell
- Runtime ดาวน์โหลดจากแหล่งทางการ + ตรวจ SHA-256/512 (ngrok ตรวจลายเซ็น Authenticode)
- ไม่ยอมรับ Minecraft EULA แทนผู้ใช้, ไม่แก้ router/firewall โดยไม่ได้รับอนุญาต, ไม่ปิด Firewall ทั้งระบบ

## 11. ข้อจำกัดที่ทราบ (ตามจริง)
- ยังไม่ได้ทดสอบ End-to-End กับบัญชี Cloudflare / ngrok / playit.gg / Tailscale / VPS จริง (ใช้ Mock adapter + parser tests)
- playit.gg v2: ใช้ `playitd --secret-path` ตามเอกสาร README ของโปรเจกต์; ที่อยู่สาธารณะดึงจาก log ของ agent หรือให้ผู้ใช้กรอกจากแดชบอร์ด แล้วยืนยันด้วยการเชื่อมต่อจริง
- PCP (RFC 6887) ยังไม่รองรับ (รองรับ UPnP IGD และ NAT-PMP)
- จำนวน open connections / HTTP request count ยังไม่เก็บ (แสดงเป็น “—”)
- เมื่อโปรแกรมปิด (โหมด keep servers) ไม่มี auto restart และ tunnel ปิด — ใช้โหมด Minimize to tray ถ้าต้องการให้ดูแลต่อเนื่อง
- Installer ยังไม่ได้ลงลายเซ็นดิจิทัล
